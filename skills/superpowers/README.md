# Superpowers (course selection)

Two workflow skills from [Superpowers](https://github.com/obra/superpowers) by
Jesse Vincent (MIT licensed, see `LICENSE`), pinned at v6.2.0:

- `systematic-debugging`: find the root cause before proposing any fix.
- `verification-before-completion`: evidence before claims; never say "done"
  without running the verification.

Install like the writing pack:

```bash
cp -r skills/superpowers/*/ .claude/skills/
```

The full framework has a dozen more skills (planning, test-driven development,
code review, git worktrees). Read any skill before installing it.
